# Desktop Composition System — Scrapbook, Controlled

## Structural Rule

Desktop scenes use a consistent **editorial rail + evidence board** relationship. A chapter’s label, title, and short explanation occupy a controlled leading rail. The remaining width is reserved for one clear evidence board: a hero collage, project board, repository object, skills board, timeline, award stage, or contact console.

## Layout Rules

| Element | Desktop system |
| --- | --- |
| Content measure | `min(1280px, calc(100vw - 12vw))` with a repeatable 32px internal rhythm |
| Chapter rail | 300–360px; labels, titles, and explanations align to its left edge |
| Evidence board | Remaining space; one primary object plus one supporting object, never three unrelated focal objects |
| Section vertical scale | 620–780px for visual chapters; no empty color fields that lack a deliberate object or information purpose |
| Project proof | Primary card spans the left board column; two secondary cards align as a stable right-hand stack |
| Timeline / awards | Shared baseline, predictable card heights, readable metadata |

## Visual Rules

The warm paper base, dark navy type, pink, lime, yellow, and cobalt remain the portfolio’s ownable scrapbook language. The correction changes their **density**, not their existence. Each scene gets one quiet base, one primary accent, and one support accent. Heavy outlines remain for evidence objects only; background decoration becomes lighter, smaller, or absent.

Typography becomes more dependable: Space Grotesk carries all major headings; Caveat is restricted to a single accent phrase per chapter; DM Mono supports labels and metadata. Decorative treatments may not compete with a chapter title or primary CTA.

## Interaction Rules

Motion should explain focus, not fill empty space. The hero collage, repository carousel, and project cards retain their responsive movement. Secondary perpetual effects are reduced on desktop so the composition can breathe. The desktop dock appears only after the hero and acts as navigation—not a new focal object.

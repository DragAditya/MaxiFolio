# Peak Interaction Research

The referenced **Scroll Media Expansion Hero** by Arunachalam was available through the 21st.dev catalogue. Its useful interaction principle is a compact hero visual that grows into a dominant media field as the visitor scrolls. The portfolio will adapt this as a scroll-linked expansion of the existing collage artwork, not copy the component wholesale.

The requested **Coverflow Carousel** preview encountered a Vercel browser verification checkpoint. The visible design intent is still clear from the request: a focused center project with neighbouring projects angled in depth. The portfolio will build a local, accessible coverflow interaction for GitHub projects using buttons and keyboard-safe state rather than relying on the blocked preview.

Sources: <https://21st.dev/community/components/s/hero?preview=%2F%40arunachalam%2Fcomponents%2Fscroll-expansion-hero> and <https://21st.dev/?preview=%2F%40ruixen.ui%2Fcomponents%2Fcoverflow-carousel>.

The **Parallax Scrolling** component by Osmosupply confirms a layered depth treatment built around scroll-linked relative motion. The portfolio will use a contained version for floating stickers and hero media, avoiding transform-heavy motion on every section. The **Horizon Hero Section** preview showed a soft layered hero direction but became sign-in gated; its usable principle is a broad visual horizon behind concise copy. The existing colourful hero collage will become a focusable media layer with controlled parallax rather than adding a competing second hero style.

Sources: <https://21st.dev/community/components?q=zoom+parallax&preview=%2F%40osmosupply%2Fcomponents%2Fparallax-scrolling> and <https://21st.dev/community/components?q=zoom+parallax&preview=%2F%40lovesickfromthe6ix%2Fcomponents%2Fhorizon-hero-section>.

# Requested ReactBits Dock Adaptation

The provided ReactBits Dock reference defines a panel with `items`, `panelHeight`, `baseItemSize`, `magnification`, `distance`, and spring options. The user requested the following concrete values:

| Setting | Value |
| --- | ---: |
| Panel height | 60px |
| Base item size | 40px |
| Hover magnification | 70px |
| Proximity distance | 200px |

The portfolio adaptation will use the same pointer-proximity magnification behavior with navigation items for Home, Work, GitHub, Skills, Story, and Contact. It will be original to this portfolio: warm paper glass, outlined scrapbook controls, existing pink/lime/blue accents, plus a compact touch-safe mobile treatment. The reference page lists Motion as its animation dependency; this project already uses Framer Motion.

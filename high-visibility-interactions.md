# High-Visibility Interaction Pass

This pass deliberately increases visual contrast so the interaction changes are obvious on the first visit. The hero will use a deeper pointer tilt, stronger floating depth, a visible light sweep over the visual frame, and an animated chrome frame around the collage. Project cards will gain large glass “open” overlays, larger lift/rotation, image zoom, and a colour bloom. Project actions, carousel controls, repository actions, contact links, and the main CTA will all share a clearly visible glass surface with an animated iridescent sweep.

Desktop uses the full effect. Mobile keeps image zoom, glass highlights, press feedback, and visual depth while removing pointer-only behavior. Motion remains disabled for people who select reduced motion.

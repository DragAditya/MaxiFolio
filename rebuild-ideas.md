# Ground-Up Portfolio Rebuild

## Three Possible Directions

| Theme Name | Very Brief Intro | Probability |
|---|---|---:|
| **Chromatic Index** | A museum-like personal operating system where work, capabilities, and achievements behave as color-coded entries in a living index. It is bright, exact, and unexpectedly playful. | 0.06 |
| **Monumental Utility** | A quiet typographic archive with dense information bands, high-contrast proportions, and deliberate interaction. It feels more like a well-designed tool than a marketing page. | 0.03 |
| **Luminous Workshop** | An optimistic material lab that uses polished paper, kinetic diagrams, and small moments of color to make technical work feel approachable and real. | 0.08 |

## Selected Direction — Chromatic Index

### Design Movement

Contemporary Swiss editorial design meets a highly polished Apple product index. The site will behave like a curated personal operating system rather than a conventional scroll portfolio.

### Core Principles

The rebuild prioritizes **information as interface**, **intentional contrast**, **kinetic utility**, and **legible personality**. Every section should work as a distinct product surface with a concrete job: orient, prove, explain, or invite contact.

### Color Philosophy

Warm paper white establishes focus and trust. Ultramarine conveys technical command; persimmon introduces human energy; graphite anchors information without making the portfolio feel like a generic dark developer site. Color is used as a classification signal, not a decoration.

### Layout Paradigm

The page uses a modular **index-board** instead of stacked landing-page bands. Wide editorial panels, pinned metadata, and interactive card clusters create a progression that feels assembled from meaningful artifacts rather than generic sections.

### Signature Elements

The signature motifs are a live section counter, index-label pills that transform on hover, and a multi-color signal bar that changes state as the visitor moves through the portfolio.

### Interaction Philosophy

Interactions should clarify the shape of the information. Projects open into layered proof drawers; category cards expand only enough to reveal relevant detail; the navigation behaves like an intelligent index rather than a set of links.

### Animation

Motion follows an articulate 180–420ms spring curve. Use blur-to-focus text, magnetic CTA motion, depth-aware cards, elastic tabs, animated counters, and clip-reveal imagery. Avoid continuous decorative animation; apply all movement only to navigation, choice, emphasis, and state change. Respect reduced-motion preferences completely.

### Typography System

Use **Manrope** for confident, crisp display copy and **IBM Plex Mono** for metadata. Headlines are compact but breathable; metadata is small, systematic, and never competing with the main statement. Italic treatment is absent—the typography gains character through scale and layout.

### Brand Essence

**A software builder’s personal operating system for turning complex workflows into clear, usable products.** Personality: **precise, energetic, pragmatic**.

### Brand Voice

Headlines are direct, present-tense, and operational. CTAs sound like meaningful next moves, not marketing boilerplate. Example lines: “Make the workflow lighter.” and “Open the proof, not the pitch.”

### Wordmark & Logo

The mark is an `AW` monogram built from two offset index brackets and a signal dot. The wordmark uses split alignment—`ADITYA` and `WAGH` occupy adjacent modular cells rather than a conventional single line.

### Signature Brand Color

**Signal Cobalt — #0A5CFF.**

## Style Decisions

The original Chromatic Index treatment is refined into a **Mineral Index** implementation. Broad section grounds use only warm porcelain, soft silver, graphite, and dark-navy evidence chambers. Signal Cobalt is the sole saturated accent, reserved for active index markers, instrument dots, rare text emphasis, and directional feedback. The desktop orbital rail is the primary narrative structure; the top navigation stays a low-emphasis utility layer. Project cards are glass technical slabs with metadata, hairline structure, orbital geometry, and quiet illumination rather than solid-color posters. The AW orbital identity is consistent from the hero artifact through the final contact chamber.

## 21st.dev Pattern Inventory

The rebuild combines the already retrieved **Blur In Text** and **Dock Nav** sources with catalogue-informed adaptations of **Magnetic Button**, **Scroll Progress**, **Tilt Card**, **Bento Grid**, **Animated Tabs**, **Marquee**, **Accordion**, and **Command-style navigation**. Because the connected 21st.dev account has no remaining code retrievals today, additional patterns will be reproduced in the project’s own React, Tailwind, and Framer Motion vocabulary rather than fetched as opaque third-party code.

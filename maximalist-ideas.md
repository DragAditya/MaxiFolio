# Maximalist Pinterest Portfolio Direction

## Chosen Style — Creative Developer Scrapbook

The portfolio will feel like an energetic Pinterest inspiration board made by a serious developer: layered paper panels, oversized type, taped visual notes, colourful gradients, cut-out illustrations, stickers, small handwritten-style labels, and varied card sizes. It will be full, playful, and visual without making the important information hard to read.

The colour system uses hot pink, saturated cobalt, bright lime, buttery yellow, and deep ink. Every major section gets one strong colour story, while body text sits on light paper panels for easy reading. The page structure is simple: a strong introduction, project collage cards, skills stickers, timeline notes, achievement cards, and a fun contact board.

The new visual assets will include a hero collage, three project-specific abstract illustrations, and an AW sticker-style brand icon. The page will use subtle floating and tilt motion, but no complicated hidden interactions.

## Style Decisions

The visual review recommended returning to the earlier quiet-mineral direction. That recommendation is intentionally not adopted because the user explicitly requested a **maximalism-style, Pinterest-inspired** portfolio. The accepted improvement is clearer, practical project copy: colourful collage visuals stay, while labels and descriptions explain the software in direct English.

## Peak Interaction Review Decision

The interaction review again recommended replacing the colourful scrapbook visual language with Quiet Precision. This conflicts with the user’s explicit request for a maximalist Pinterest aesthetic, so the collage palette, paper layering, and playful type remain. The accepted quality rule is that interaction effects and GitHub carousel details must make projects easier to explore, never make the content harder to read.

## Glass and Depth Addendum

The supplied reference imagery is not used as website content. It informs original chrome-glass hover layers, restrained iridescent highlight motion, deep-space contrast, editorial cobalt flashes, and ASCII-style interaction mood. The overall Pinterest scrapbook direction remains the active user-selected style; quiet-mineral review recommendations conflict with that request and are therefore not adopted.

## High-Visibility Interaction Decision

The latest style review repeated the Quiet Precision recommendation. It is not adopted because the user requested clearly visible **Pinterest-style maximalism** and asked for a stronger rather than quieter interaction pass. The accepted rule is that stronger effects must make actions obvious: visible 3D hero depth, chrome sweeps, large glass button response, and direct project-open overlays.
